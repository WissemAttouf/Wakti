# Captures d’écran — Wakti

Placez dans ce dossier les captures d’écran de l’application Wakti, puis référencez-les dans le README principal avec des chemins relatifs, par exemple :

```md
![Accueil de Wakti](docs/images/accueil.png)
```

## Noms de fichiers suggérés

- `accueil.png` — écran d’accueil
- `coran.png` — navigation ou lecture du Coran
- `lecture-audio.png` — lecture audio et choix du récitant
- `horaires-priere.png` — horaires de prière
- `calendrier-hijri.png` — calendrier hégirien
- `parametres.png` — thèmes et préférences
- `mobile.png` — affichage sur mobile

Utilisez les noms correspondant aux fichiers réellement téléversés. Les chemins et la casse doivent correspondre exactement aux noms dans GitHub.
